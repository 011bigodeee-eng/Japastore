# Japa Store

Projeto de site e catálogo digital para uma loja de roupas.

## Funcionalidades desejadas
- Visual moderno e adaptado para celular.
- Catálogo com fotos, preços, tamanhos e cores.
- Filtros por categoria de roupa.
- Destaque para novidades e promoções.
- Botão para fazer pedidos pelo WhatsApp.
- Painel para adicionar, editar e remover produtos.
- Links para Instagram e contato da loja.
